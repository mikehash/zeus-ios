# Reply-length row — walk (before code)

Base: zeus-ios main `903e590`. Walk-only. The code commit follows once this lands.

## Where the system prompt comes from on the phone
- The phone has no way to override the prompt. The pinned core assembles it APPEND-ONLY: `get_context` → `AGENTS.md` first.
- The bridge owns the phone's prompt text through `phone_agents_body(model)` (`rust/zeus-core-bridge/src/lib.rs:1035`).
- `make_agents_honest` writes that text (`:1178`). It is called at `init` (`:367`) and again from `set_provider` (`:471`).
- It rewrites the file only if it finds `DESKTOP_MARKER` or `PHONE_MARKER`. Any other file is left byte-for-byte.
- So a reply-length setting has exactly one honest place to go: a section in `phone_agents_body`. Swift pre-pending text to every turn would put instructions inside the operator's message, which is the "reference read as instruction" shape the attach arc rejected.

## Shape
1. **Rust:** add an `enum ReplyLength { Brief, Normal, Detailed }` (uniffi::Enum).
   - `phone_agents_body(model, length)` adds a `## Replies` section.
   - `Normal` adds NOTHING, so a fresh install's prompt is byte-identical to today's. Same default-is-unchanged rule as rate and chime.
2. **Rust:** `ZeusCore` holds `length: Mutex<ReplyLength>` and the last rendered model.
   - New export `set_reply_length(length)` re-renders through the SAME `make_agents_honest`, keeping the guard: a stranger's file stays untouched.
   - `set_provider` renders with the stored length, so arming a route can't silently drop the setting.
3. **Swift:** a `ReplyLengthPreference` in UserDefaults, plus a Settings row (BRIEF / NORMAL / DETAILED) that cycles it.
   - It is pushed to the core when the core is armed and when the row is committed. There is one write path.
4. Bindings are regenerated by `build-xcframework.sh` and committed in the same commit.

## Proposed prompt text (THE DIFF TO REVIEW)
- **Brief:** `## Replies\n\nThe operator chose BRIEF replies. Answer in one to three short sentences unless they ask for more. Replies are often spoken aloud on this device — no tables, no code blocks unless asked.\n`
- **Normal:** *(no section)*
- **Detailed:** `## Replies\n\nThe operator chose DETAILED replies. Give complete answers with reasoning and steps where useful. Replies may be spoken aloud on this device, so prefer prose over tables.\n`

## Honest limit — the gateway arm
On `.resolved` (remote gateway), the prompt is built server-side, so the phone's AGENTS.md is never read. The row therefore applies ON THIS PHONE ONLY. When a gateway is resolved, the row shows that scope (`Theme.joined(["REPLY LENGTH", "ON-DEVICE CORE ONLY"])`) rather than claiming a setting it can't enforce.
